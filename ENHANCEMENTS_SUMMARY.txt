CONFIGURATION OPTIONS
================================================================================

All configurable via environment variables (no code changes needed):

  HYBRID_SEARCH_ENABLED=true         Enable/disable hybrid search
  HYBRID_CACHE_ENABLED=true          Enable/disable semantic cache
  HYBRID_CACHE_TTL=86400             Cache expiration (seconds)
  HYBRID_RRF_ALPHA=0.5               Hybrid fusion weight
  HYBRID_RERANK_ENABLED=true         Enable/disable cross-encoder
  HYBRID_RERANK_MODEL=BAAI/...       Which reranking model to use

All have sensible defaults. Just deploy and it works!
